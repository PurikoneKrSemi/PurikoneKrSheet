풀오토·심연토벌전 모바일 테이블 변환 도구

원본 HTML을 선택하면 모바일 화면에서만 딜량·조작을 아래쪽 행으로 이동하도록 변환한 HTML을 다운로드합니다. 원본 파일은 덮어쓰지 않습니다.

파일을 선택해 주세요.

변환 규칙

  • CR 행이 있는 일반 풀오토: 모바일에서 3행 × 6열 형태로 표시합니다.
  • CR 행이 없는 일반 풀오토: 모바일에서 2행 × 6열 형태로 표시합니다.
  • 마지막 행은 딜량 | 딜량 데이터 | 조작 | 조작 데이터를 배치합니다. 조작 데이터 셀은 3열을 차지합니다.
  • 심연토벌전처럼 테이블 안에 여러 thead/tbody 구간이 있는 경우도 각 구간별로 처리합니다. 상단 공략 링크 행과 섹션 헤더는 유지합니다.
  • 데스크톱에서는 원래 테이블을 그대로 유지하고, 모바일에서만 재배치합니다.
변환된 HTML은 기존 테이블 데이터를 삭제하거나 덮어쓰지 않고, 화면 폭에 따라 원래 행과 모바일용 행을 전환하는 스크립트를 추가합니다.
